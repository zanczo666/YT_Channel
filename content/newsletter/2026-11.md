# Systematic Trading Lab — November 2026

Hi,

This is the monthly lab note: what went into the strategy pipeline, where it fell out, and one thing we learned along the way. The numbers below come from the October funnel report, the most recent one available.

## 1. The funnel

The registry only covers strategies that reached the Python backtest. Earlier stages (research hypotheses, the generator smoke gate) and later stages (out-of-sample, walk-forward, Monte Carlo, costs, paper/live) have no numbers yet — so you'll see "no data" there, not an estimate.

|---|---:|---:|---:|---|

| Generator / smoke gate | no data | no data | no data | — |
| Python backtest / parity | 45 | 2 | 43 | quality gate: 37, zero signals: 6 |
| MT5 backtest | 6 | 1 | 5 | not enough trades and no edge; in 2 cases also drawdown too large |
| Validation (OOS / WFA / MC / costs) | no data | no data | no data | — |
| Paper / live | no data | no data | no data | — |

A few things worth spelling out:

- **45 variants tested, 2 got through Python.** Most of the drop-outs (37) failed the quality gate. Six never produced a single signal.
- **The MT5 stage includes a control group.** Five of the six strategies run in MT5 were sent there on purpose as controls, four of them after being rejected in Python. Those four dropped out in MT5 as well, which is what you'd want: the Python gate and MT5 agreed.
- **One strategy passed MT5.** That is one step, not a result. It hasn't been through validation yet, and most strategies don't survive that stage.

## 3. One lesson: the same indicator, two different numbers

One of the bugs found this month: the strategy generators computed ATR differently from MT5. The generators used Wilder's smoothing; MT5's built-in ATR uses a simple average of the true range. Same name, same period, different values — so any stop, filter or position size built on ATR quietly drifts between the research environment and the trading platform.

**The general rule:** "ATR(14)" is not a full specification. Before you compare a backtest from one tool with another, check how each one *averages* the indicator, not just its period.

**How to check your own setup:** compute the indicator in both environments on the same bars and diff the values bar by bar. If they don't match to a few decimal places, fix that before you compare any strategy results.
