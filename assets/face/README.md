# Zdjęcia twarzy do miniatur

Wgraj tu 3–5 zdjęć (najlepiej PNG z przezroczystym tłem — wycięte np. w darmowym remove.bg / Canva Free):
- `face-neutral.png` — spokojny, patrzy w kamerę,
- `face-skeptic.png` — lekko sceptyczny (do FAIL / Graveyard),
- `face-explain.png` — tłumaczy, gest dłonią (do Validation Gates),
- opcjonalnie `face-pass.png` — lekki uśmiech (do PASS).

Format: min. 1000 px wysokości, ramiona w kadrze, dobre światło z przodu. Pliki obrazów są w `.gitignore`
(nie trafiają do repo); trzymaj kopię u siebie.
